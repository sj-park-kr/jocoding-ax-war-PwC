## 1. 목적
- 과제: **가상 화장품 그룹 Aurora의 AI 운영 시스템** 만들기
- 배경: Aurora 30개월 데이터. 마케팅·생산·품질·재무가 같은 회사를 서로 다른 숫자로 봐서 판단 지연·부서 간 갈등 발생
- 목표: 처리할 일이 들어오면 AI와 사람이 함께 판단하고 **승인·처리·상태 변경까지** 이어지는 시스템
- 성격: 채용형. 모집 부문 FDE(개발자/컨설턴트), 채용 1~9명, 면접 최대 40명, 채용 결정은 삼일PwC
- 인재상: 고객·현장 문제를 찾아 AI로 실제 해결책을 만드는 사람. 전공·이전 직무보다 문제를 풀어 온 과정을 봄. 개발 경험 필수 아님

## 2. 진행 흐름
1. 문제 확인 — 8개 업무 중 1개 선택 (업무 흐름도 + 원본 데이터 zip 제공)
2. **문제 풀이 환경 세팅 (필수, 가장 먼저)** — https://axacademy.ai/axwar/samilpwc-1/setup
3. 풀이·배포 — AXHub 선택(권장)
4. 제출 — 1차 선정 → 삼일PwC 면접 → 채용 결정

## 3. 평가 기준
| 기준 | 핵심 질문 |
|---|---|
| ① 기업 운영 이해·기획 | 누구의 어떤 결정을 개선하나? 앞뒤 부서의 목표·제약과 어떻게 연결되나? 전문성 확장이 왜 필요한가? |
| ② 데이터 근거 판단 | 필요한 정보를 스스로 정의했나? 자료의 의미·관계·시점·한계를 이해했나? 정보 공백·가정·제약을 일관되게 설명·검증하나? |
| ③ 작동하는 운영 시스템 | AI가 실제 판단·처리에 쓰이고, 사람·도구와 연결되어 승인 이후까지 이어지나? |
| ④ 변경·예외 대응 | 정보 부족·정정·거절 시 영향을 확인하고 대안·계획을 조정하나? |

- + AI 활용 기록과 직접 만든 AI 지침·스킬(`CLAUDE.md`, `.claude/skills` 등)도 채점에 반영
- ⚠️ **BI 화면이나 권고문 생성만으로는 ③ 인정 안 됨**

## 4. 제공 도구·혜택
- **AXHub** (선택, 권장): 배포·DB·로그인 인프라 제공, 첫 가입 10,000 크레딧, Claude Code·Codex 공식 지원

## 5. 키포인트
1. **세팅 먼저** — 세팅 전 작업은 기록되지 않아 AI 활용 과정 미채점
2. **"보여주기"가 아니라 "처리하기"** — 승인, 상태 변경, 다음 부서로 넘기는 흐름이 실제로 동작해야 함
3. **예외 시나리오를 설계에 포함** — 정보 부족·정정·거절 케이스를 시연 영상과 설계 설명에 담기
4. **부서 간 숫자 불일치를 데이터로 설명** — 정의·시점·한계, 가정을 명시
5. **AI를 어떻게 지휘했는지도 평가 대상** — `CLAUDE.md`, 스킬 파일을 정성껏 작성하고 제출물에 포함
6. 이 저장소는 이미 AXHub에 연결됨 → 권장 경로(AXHub 배포)로 진행
