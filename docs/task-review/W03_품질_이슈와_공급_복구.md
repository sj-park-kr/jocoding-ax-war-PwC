## 2. 솔루션안

### A안: 회수 범위 판정과 위원회 상정 콘솔
- **사용자**: 품질팀장이 범위 결정, 품질위원회 의결
- **흐름**: 클레임 접수 → 배치 불량률 두 분모로 계산 → 로트 공유 형제 배치로 범위 확장 → SBL·SH로 고객 노출 탐색 + 신뢰등급(확인/추정/미확인) → AI가 근거 인용 상정안·대안 작성 → 위원회 승인 시 배치는 회수확정, 형제 배치는 출하보류·추가검사 → 영업(고객 통지)·물류(회수)·재무(매출 차감)·구매(V-205 클레임) 할 일 생성
- **AI 역할**: 클레임·뉴스 분류, 불일치 탐지(C-105 미매핑 등), 상정안 초안, 이벤트 발생 시 재계산. **10% 판정은 결정론 규칙, AI가 확정하지 않음**.

- 난이도: 중하

### B안: 공급 복구 플래너
- SCM·영업이 대체 물량 배분 결정. 회수량 → 고객별 부족량 → V-205 다음 로트 입고·검사, L-02 잔여 3% → 배분안(`revenue_share_pct`, C-101 30%) → 품질 재승인 → 영업 승인 → 생산계획·납기 갱신.

- 합성 비중 큼, 가정 미명시 시 감점. 난이도: 중상

### C안 (권장): A 핵심 + B 축소, 사건 케이스 상태머신
- **상태**: 접수 → 조사 → 상정 → 의결/반려 → 회수 진행 → 재공급 승인 → 판매 재개
- **필수 확장 후보**: 형제 배치 처리 규칙(로트 기준 출하보류 vs 배치 기준 회수) / SBL-SH 매핑 신뢰등급
- **다른 부서 영향**: 영업(C-101 재협상, 발주 감소) / 구매(V-205 독점·MOQ 위약 아래 대체 로트) / 생산(L-02 97% 병목) / 재무(매출 차감)
- **조건 변경**: 신규 클레임으로 형제 배치 10% 이상 / 판정 True→False 정정 시 회수 재심사 + 미실행 작업 취소 검토·실행 완료 건 후속 조치 / V-205 신규 로트 불합격 → 재공급 지연
- **정보 부족·거절**: C-105·C-109처럼 SBL에 없는 고객은 "추정" 표시 + 고객 보유 확인 요청 / 위원회 반려 시 조사 계속 + 재상정 기한, 기준 충족 건은 "인과 미확정 이유로 지연 불가" 경고
- 난이도: 중 (클레임 165건, SBL 1,431건 → 정적 사이트 + JSON도 가능)

## 3. 함정·리스크
- 언론 보도(`ext_news_quality_incident.md`: 단일 매체, 제품 미지목)로 전면 회수 → 과잉 대응
- `status=종결`을 미확정으로 오독. True·종결 19건, False·종결 29건 → 판정은 반드시 `defect_confirmed`로
- 형제 배치(합격, 클레임 0) 회수 = 정책 위반성 과잉 대응 / 방치 = 지연 대응 → **출하보류·추가검사 중간 상태 필요**
- SBL만 믿고 C-105 누락 / 원본 물질수지·시점 오류를 실제 이상으로 서사에 넣음
- 공급사 회신을 항상 유리하게 가정한 성공 시연 (A03 감점 명시)
- AI가 회수 자동 확정 → 권한 위반
- BI 대시보드에서 끝남 → 승인 후 상태 변경·부서별 할 일 생성까지 필요

## 4. 출제자 관점 — 꼭 보고 싶은 장면 3가지 (시연 뼈대)
1. **로트 정방향 추적**: 확정 클레임 입력 → 두 배치 회수 대상 계산·위원회 상신 → 같은 로트의 합격 배치 2개 자동 노출 → 회수가 아니라 보류·조사·고객 확인 작업으로 분기. 규칙과 사람 승인이 구분.
2. **정정·거절 재검증**: 클레임 일부가 확정→미확정 정정 → 불량률 10% 아래 → 회수 재심사·변경 승인(기존 이력 보존) / 위원회 거절 → 재상신 작업 / C-105처럼 출하 매핑 없는 건은 '미확인'으로 영업에 확인 요청.
3. **다른 부서 실제 반영**: 재공급 계획이 L-02 여력과 충돌 → Masil 더마 SKU 발주·판매 배분, C-101 우선 납품이 실제로 갱신.

추천 이유(출제자): 데이터로 증명되는 함정이 가장 선명(형제 배치, SBL 공백, 10% 규칙), 상태 기계가 자연스러워 ③④가 억지 없이 나옴, 다른 부서 영향이 실제 숫자로 연결, 경쟁 밀도 중간.
