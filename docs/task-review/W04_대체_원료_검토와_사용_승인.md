# W04 대체 원료 검토와 사용 승인

## 최종 승인자 검토 (2026-11-11)

**최종 82/100 · 5위** — 기획 / 데이터 / 운영 구현 가능성 / 변경·예외 = **19 / 18 / 24 / 21**. 보완 반영 전에는 77점(18 / 17 / 23 / 19)이었다. 배점은 20/25/30/25이며 공식 배점이 아니다. 아래 승인 조건을 설계에 반영했다고 가정한 제안 점수이고 구현 완료 승인은 아니다. [공통 기준과 최종 순위](00_종합_업무선택.md).

사용 승인과 후속 생산 변경이라는 구조는 타당하다. 예시 반복을 모범답안 신호로 보는 해석은 철회한다(A03 §3·§4).

- M-B 2025년 구매 **8,455,149,159원 / 전체 14,261,720,168원 = 59.29%**. 구매 첫 행 환율 1,324.68, 마지막 1,480.69이며 투입 적용단가와 시점이 다르다.

- M-B 입고 **65,782.5kg**, 투입 **606,469.92kg** 불일치는 A05 공개 한계다. 이를 실제 위반 확정 근거로 사용하거나 원본 수정으로 메우지 않는다.

- SKU-1003은 커버 **4.3주**로 4주 이상이다. 원본에는 후보 규격·시험 기준·사용 승인권자 자료가 없어 추가 가정과 증빙 요청이 필요하다.

- 조건부 승인은 미검증 원료 사용 허가와 구분한다. 안정성 자료 미비는 사용 승인 보류로 처리한다. 특정 시험기간·규제 요건은 원본 사실이 아니므로 교육용 가정 또는 별도 확인 대상으로 둔다.

- **승인 조건:** M-B·PL-02·후보 1개, 승인 매트릭스·서류 미비·불합격 회신·시험 슬롯 변경. 원료 수불 정정표는 선택 확장이며 필수 전체 복구 과제가 아니다.

### 보완 반영 재평가 (2026-11-11)

- **회복한 감점 (+5):** 조건부 승인과 사용 승인 구분, 기존 권한 차용 금지(기획 +1, 예외 +1). 구매 환율과 투입 적용단가의 시점 구분(데이터 +1). 승인 매트릭스를 발주안·시험 슬롯에 연결(구현 +1). 자료 미비·불합격 회신과 시험 슬롯 변경의 모의 처리(예외 +1).

- **보완해도 남는 감점:** 후보 원료 자료와 사용 승인 기준·승인권자가 원본에 없다. 운영 중 AI가 읽을 후보 서류도 전부 합성이다. 원료 수불 불일치는 그대로다.

### 초기 리뷰와의 관계

아래 초기 점수는 비교 이력이다. 본 최종 의견과 충돌하면 최종 의견을 따른다. 본문의 ‘출제자 관점’, 경쟁 밀도·참가자 비중·채용매력·가점 예측은 초기 페르소나 추정이며 최종 점수의 근거가 아니다.

## 1. 데이터에서 확인한 사실

### 단일 공급처 사슬 (원본 키로 확인)
- `m_sku_ms.product_id` 더마 SKU-1001~1004 → `m_product_cv` PL-02 (main_material_id=M-B, is_f1_dedicated=True)
- PL-02 → `m_material_cv` M-B (특허 활성성분, 해외 USD) → 공급처 **V-205**, is_exclusive=True, contract_type "2년 장기+MOQ+자동갱신·위약"
- `id_conventions.md`에도 "V-205(더마 독점)"

### 규모·원가
- M-B 구매액(`procurement_material_purchase_cv.amount_krw`) 2025년 **84.6억, 전체 원료 구매의 약 59%**
- unit_price_fx 148.0 USD(2024-07) → 170.2 USD(2026-06), +15%
- fx_rate_applied 1,325 → 1,480, +11.7%
- `applied_unit_cost_krw` 195,360 → 250,626, **약 +28%**
- `strat_capacity_cv` L-02(PL-02) 가동률 97%

### 후속 부서 제약
- `sku_inventory_ms.stock_cover_weeks` 더마 4종 중 3종이 `m_sku_ms` 안전재고 하한 4주 미달. SKU-1003은 4.3주로 하한 이상이며 더마 리드타임은 12주다.

- `strat_capex_plan_cv` OPT-02(F2 전환): "원료(M-B) 재계약·처방 재검증 필요" → W04 결과가 W05(C-201 입찰)의 전제 조건

### 함정·공백
- **대체 후보 데이터 전무**: 규격·COA·안정성·규제·샘플 평가 자료 없음(W04.html "미해결 지점" 명시) → 후보 자료는 전부 합성 또는 확인요청
- **사용 승인권자·절차 미정의**: `approval_authority_policy.md`엔 품질 회수(품질위원회)만. W04.html이 "회수·CEO 권한을 임의로 전용하지 말라"고 경고
- **수불 불일치**: M-B 로트 입고 합계(`material_lot_master_cv.received_qty`) 65,782kg vs 투입 합계(`production_material_consumption_cv.consumed_qty`) 606,470kg(약 9.2배). PO 합계 83,607kg, PO 데이터는 2024-07부터, PO-lot 연결 키 없음. → A05 공개 한계, 복구 대상 아님, "확장 자료"로 처리
- **보류 로트 투입**: LOT-B-2602-P inspection_result "보류", 입고일 2026-02-06. B-02-2602-01이 그보다 앞선 02-05에 이 로트로 생산. 이 로트 배치 4개 중 B-02-2602-01·B-02-2603-01에서 `qc_claims_cv` 확정 클레임 45건 → "보류 로트 투입 차단" 입고 승인 게이트의 근거, W03 연결
- **Celtonic은 대체재 승인 근거 없음**: `celtonic_contract_summary.md` 단가·해지조항 미확인, 인터뷰도 "원료 공급 안정성 확인"을 선행조건으로
- `ext_fx_daily.csv`는 2024-07-01부터 → 로트 데이터(2024-01~)와 기간 불일치

## 2. 솔루션안

### A안 (추천): M-B 대체원료 변경관리(Change Control) 운영 시스템
- **사용자·결정**: 구매 리드 후보 등록 / 연구·품질 회신 / 사용 승인권자(교육용 가정: R&D·QA 공동 승인)가 "어떤 후보를 어느 제품에 어떤 조건으로 쓸 수 있는가" 결정
- **흐름**:
  1. 후보 등록(합성 V-3xx, Celtonic CT-01)
  2. AI가 서류 체크리스트로 충족·누락 판정(COA 항목, 규격 범위 대비, MSDS, 규제·특허, 안정성 기간)
  3. 게이트별 상태 전이: 후보 → 서류검토 → 샘플/랩평가 → 파일럿 배치 → 조건부승인 → 사용승인 / 거절 / 보류
  4. 승인 시 후속 계획 3개 자동 갱신: 발주안(V-205 MOQ·위약 유지분과 대체 분할 비율) / L-02 생산계획(97% 가동 중 시험배치 슬롯) / Masil 더마 SKU 커버 재계산
- **AI 역할**: 후보 서류 규격값 추출·기존 규격 대비 차이 판정 / 근거 누락 항목 확인요청서 생성 / 승인 조건 구조화(예: "PL-02 중 SKU-1003만, 파일럿 3배치 합격 후") / 거절·정정 시 영향 계획 재산출
- **변경**: 환율 1,550 상승, V-205 단가 인상 → 후보 TCO 순위 변경 / 대체 후보 리드타임 증가 → Masil 커버 공백 주차 재계산
- **정보부족·거절**: 안정성 데이터 없음 → "조건부: 신규 처방 적용 불가, 기존 생산 지속" 보류 + 확인 작업 / 품질 거절 → 대체 발주안 취소, V-205 물량 복귀, MOQ·Masil 커버 경고를 Masil SCM에 전달
- **필수 확장**: 원료 규격·사용승인 매트릭스(원료 × 제품 × 조건) (로트 수불 정정표는 선택 사항)
- **다른 부서 영향**: 생산(L-02 시험배치로 생산량 감소), Masil SCM(커버 4주 미달), 영업(C-201 OPT-02 조건)
- **난이도**: 중 (정적 사이트 + 상태 JSON, 또는 AXHub DB 테이블 4~5개)

### B안: 단일소싱 리스크 레이더와 이중화 착수 승인
- V-205가 X주 공급 중단 시 PL-02 생산 공백·Masil 품절 주차 계산 → 안전재고 상향 발주 또는 대체 검토 착수를 SCM·구매가 승인. 구현 하. 승인 이후가 얕아 BI 판정 위험, 수불 불일치로 정합성 약함.

### C안: Celtonic 인수 조건부 공급 검증 (W08 연계)
- 인수와 원료 사용 승인을 분리하는 게이트. W08과 겹치고 재무 실사 범위가 커서 6일 내 어려움(상).

## 3. 함정·리스크
1. 합성 후보를 유리하게만 만듦 → A05 금지. 불합격·서류미비 후보 반드시 포함.
2. 독점·MOQ·위약 조건 삭제 → is_exclusive·contract_type 무시하고 "V-205 즉시 교체"는 불인정. dual sourcing + 위약·MOQ 비용 반영.
3. 승인권자를 정책에서 끌어옴 → 품질위원회·CEO 권한 그대로 쓰면 W04.html 경고 위배. "교육용 가정" 명시.
4. 수불 불일치 복구에 시간 낭비 → 정정표 가정으로 범위 제한.
5. 실무 타임라인 무시 → 처방 재검증, 안정성 시험기간(원본 미정, 별도 가정 필요), 기능성 원료 규제 변경 → "승인 후 즉시 양산" 비현실. 리드타임 가정 명시, 그동안의 V-205 의존 반영.
6. 문서 체크리스트 UI로 끝남 → 승인이 실제 발주·생산 상태 변경으로 이어져야 ③ 통과.

## 4. 출제자 관점

- 사용 승인권자 미정의 → 품질위원회·CEO 권한 차용 말고 교육용 가정 명시.
