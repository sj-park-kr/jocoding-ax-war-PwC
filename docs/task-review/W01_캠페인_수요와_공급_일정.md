# W01 캠페인 수요와 공급 일정

## 최종 승인자 검토 (2026-11-11)

**최종 84/100 · 4위** — 기획 / 데이터 / 운영 구현 가능성 / 변경·예외 = **19 / 21 / 24 / 20**. 보완 반영 전에는 78점(18 / 20 / 23 / 17)이었다. 배점은 20/25/30/25이며 공식 배점이 아니다. 아래 승인 조건을 설계에 반영했다고 가정한 제안 점수이고 구현 완료 승인은 아니다. [공통 기준과 최종 순위](00_종합_업무선택.md).

현금 하회와 승인 상향이라는 방향은 승인하되 잔액·입고일·품절 확정 표현은 수정한다.

- 6/30 종가 5,148,063,540원 + 7/21까지 AR 1,234,670,633원 − PO 미연결 AP 441,224,214원 − PO 3,749,760,000원 = **7/21 잔액 2,191,749,959원**. 최저 **1,921,839,555원**, 8/23 회수 후 **3,328,583,411원**이다. 기존 수치와의 차이는 MAR-0001 275,408,316원 누락으로 설명 가능한 크기이나 원인 확정은 아니다.

- 원본 날짜 기준 하회는 7/21~8/22, 약정 검사 대상은 7/21~8/21의 **24영업일**이다. 8/23은 일요일이며 다음 영업일 이월 가정이면 회복일은 8/24다. 공식 전망과 차이의 원인은 미확인이다.

- PO 14건 지급일 7/21·총액 37.4976억원은 확인. 리드타임은 **6·8·12주**, 발주일+리드타임은 **8/3~9/18**이며 확약 ETA가 아니다.

- SKU-1001 최근 4주 평균 **7,910.5개**, 커버 **2.923주**. 운송중 포함 4.923주는 별도 지표다. 기존 PO와 운송중 물량의 중복 여부·ETA가 없어 품절일을 확정할 수 없다.

- 16주 목표·기존 PO 별도 합산 가정 시 부족량은 **63,624개**. MOQ 배수 발주까지 가정하면 72,000개·15.7248억원이며 신규 지급일도 가정이다.

- **승인 조건:** SKU 1개·캠페인 1건부터 구현. ETA 확인 회신과 수요 정정이 재고·현금·승인 경로·캠페인 계획을 함께 바꾸게 한다. 자료 근거: Masil inventory 3종, financials AR/AP/일보/전망, m_sku_ms.

### 보완 반영 재평가 (2026-11-11)

- **회복한 감점 (+6):** SKU 1개·캠페인 1건으로 범위 한정(기획 +1, 구현 +1). 잔액·입고일·품절 표현 정정(데이터 +1). 지급일별 승인 경로(예외 +1). 입고 예정일 회신·수요 정정·CEO 거절 대안의 모의 처리(예외 +2).

- **보완해도 남는 감점:** 미래 캠페인 수요와 입고 예정일이 원본에 없다. 표본 주문은 전사 수요로 환산할 수 없다.

### 초기 리뷰와의 관계

## 1. 데이터에서 확인한 사실

### 쓸 수 있는 것 (회사 실제 규모)
- `sku_inventory_ms`: 14개 SKU, 2026-06-30 1회 스냅샷. 더마 4종 `stock_cover_weeks` SKU-1001 2.9 / 1002 2.9 / 1003 4.3 / 1004 2.2주. `m_sku_ms` 안전재고 최소 4주 미달, `lead_time_weeks` 12주.

- `sc_purchase_orders_ms`: SKU당 PO 1건씩 MOQ 수량(06-22~26 발주, 리드타임 6·8·12주 → 계산상 8/3~9/18 입고). 14건 37.4976억원의 `payment_due_date`가 **모두 2026-07-21 하루**.

### 가장 큰 함정: 현금 covenant 하회
- `calculation_definitions` 1.2 방식으로 재시뮬레이션: 6/30 종가 51.5억 + AR `outstanding` − AP(`po_id=NONE`분만) − PO 대금.

- 결과: 07-21 21.92억, 07-25 19.22억까지 하락 → LC-0001 90일 조건 대금 입금(08-23)에 33.29억 회복. **약 07-21~08-22 동안 30억 약정 하회 예상.**
- 공식 전망 `fin_cash_forecast_ms`는 최저 54.7억으로 하회 없음. (차이 원인이 LC-0001 결제조건 반영 여부라는 점은 추정)
- 이 구간에 현금이 나가는 신규 발주·캠페인 약정은 SCM 전결이 아니라 **그룹 CEO 승인** 대상 (`approval_authority_policy`, `covenant_terms_ms`).

### 공급 공백
- SKU-1001: 현재고+운송중 38,944개 / 최근 4주 평균 7,910개/주 ≈ 4.9주분. SPO-0001 입고 9월 중순 → **7월 말~9월 초 품절 예상**.

- 리드타임 12주 + 안전재고 4주 → 파이프라인 약 13만 개 필요, 실제 약 6.3만 개. MOQ 2~3회분(약 10~16억, 단가 21,840원) 추가 필요 → 지급일이 하회 구간에 걸림.

### 과잉재고 발주
- SKU-3001(커버 15.9주), 3002(17.8주)에도 MOQ 12,000개씩 발주(SPO-0008·0009, 4.03억). 현금 부족 시 먼저 조정할 대상.

### 공백·함정
- `mkt_orders_ms`는 대표 표본, 수량 컬럼 없음. 2026-05 표본 주문 1,499건(평월 약 2배)은 CMP-0003 라이브(CH-08)의 SKU-2001~2003. 그런데 실규모 `sku_weekly_sales_ms`엔 상승 없음 → **표본 주문을 전사 수요로 환산 금지**.

- `m_campaign_ms` 25건 모두 종료일 ≤ 2026-06-30, `product_line` 단위. 미래 캠페인 일정·SKU별 수량 없음. `mkt_budget_plan_ms`에도 SKU·기간 없음(`contract_deadline` 07-17 집중, `settlement_date`만). → **캠페인 SKU 수요 가정표는 직접 만들어야 함**.

- `sold_qty`는 품절로 깎인 값일 수 있음(censored), 품절 플래그 없음. 2026-06-29 주차가 기준일을 넘는데 커버 계산에 포함(SKU-1001 23,123/7,910=2.92로 검산).

- `in_transit_qty`에 ETA 없음. 공급자 회신 이력·PO 상태 컬럼 없음.

- Corevia `m_customer_cv`, `sales_orders_cv`에 Masil 없음 → SPO에 대응하는 Corevia 수주 없음, 회사 간 연결 합성 필요. PL-02 L-02 가동률 97%, M-B는 V-205 독점, 보류 배치 2건(LOT-B-2602-P).

## 2. 솔루션안

### 안 A (추천): 캠페인-공급-현금 정합 게이트
- **사용자·결정**: SCM 리드 발주 확정 / 마케팅 캠페인 물량·시기 조정 / 재무·CEO 하회 구간 약정 승인
- **흐름**: PLAN 선택 → AI가 캠페인 기안 문장을 SKU 수요 가정표로 구조화(상승률·기간·신뢰도·작성자·기준시점) → 13주 SKU별 재고 추이·품절 주차·MOQ 반영 발주량 → 일별 현금 재시뮬레이션으로 하회 구간과 지급일 대조 → 결재 경로 자동 판정(SCM/CEO) → 대안 제시 → 승인 → PO·PLAN 상태 변경 → Corevia에 입고 예정 확인 요청, 마케팅에 조정 통보
- **AI 역할**: 수요 가정 추출·공백 표시, 대안 생성(색조 PO 취소로 현금 확보, 캠페인을 08-23 이후로 이동, 과잉 SKU로 상품 구성 교체, 분할 발주), 근거 서술
- **조건 변경**: 마케팅 상승률 상향 / Corevia 2주 지연·부분 납품 회신 / LC-0001 결제조건 정정 → 영향받는 PO·PLAN·승인 건 재계산
- **정보 부족·거절**: ETA 없으면 '확인요청'으로 보류·확정 차단 / CEO 거절 시 대안 재계산, PLAN을 '조건부/연기'로 돌리고 마케팅 재기안 작업 생성 / 07-17 기한 임박 경고
- **필수 확장**: 캠페인 SKU 수요 가정표 + 공급자 회신 이벤트 로그
- **다른 부서 영향**: 재무 covenant 제약, Corevia L-02 97%
- **난이도**: 중 (14 SKU 수준, 정적 사이트나 간단 DB로 충분)

### 안 B: 보충발주 현금 게이트
- 14개 SKU 보충발주 제안 → covenant 기준 결재 경로 → 승인·거절에 따라 PO 재조정. 구현 하. 캠페인 연결이 약해 핵심 질문에 대한 답이 얇아짐.

### 안 C: Masil-Corevia 공급약속(ATP) 회신 루프
- 요청 → PL-02 라인 능력·M-B·보류 로트 확인 → 공급 약속 회신 → 계획 갱신. 깊이 좋으나 회사 간 데이터 대부분 합성, 6일 1인엔 위험(상).
