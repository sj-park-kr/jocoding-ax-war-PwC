- **승인 조건:** 단위·납기 확인 전 확정 물량 약속을 차단하는 조건부 입찰 1건. 영업·생산 회신으로 기존 고객 약속을 보호하고 재상신한다. 근거: capacity/capex/RFP, 주문·출하·배치·투입 CSV.

## 1. 데이터에서 확인한 사실 (원본 직접 집계)

### 생산 여력
- `strat_capacity_cv.csv` 라인 단위: L-01(기초) 1,345,035 @85%, L-02(더마) 1,949,480 @97%.

- RFP의 "F1 87%"는 단순평균. `capacity_qty` 가중 시 88.4% — data_dictionary는 가중평균 명시. 공장 평균과 L-02 97%는 다름.

- `capacity_qty` 기간 단위 미정의. `added_capacity_qty`가 "연간"이므로 연간으로 읽으면 L-02 여유 약 5.8만 EA ≪ C-201 더마 요구 150만 EA → OPT-01(180억, 36주, +160만) 또는 OPT-02(12억, 7주, +60만, 약 40%) 필요.

- 그런데 `prod_batch_log_cv` PL-02 실적은 월 46만~51만 EA(2026-01~06), 연 약 580만 EA → **L-02 능력치와 단위 불일치**. PL-01 실적 월 121만~137만 EA → L-01을 월 능력으로 보면 가동률 약 96%(표기 85%).

- 결론: 단위를 가정으로 선언하고 민감도 제시.

### 숨은 병목: 기초
- C-201은 기초(PL-01)도 연 600만 EA 요구. L-01 여유 20만 EA → 연·월 어느 단위로도 부족. `strat_capex_plan_cv`에 기초 증설 옵션 없음.

- RFP는 더마만 병목으로 서술 → 함정.

### 기존 약속
- 주문 데이터에 납기(due date)·상태 컬럼 없음.

- `sales_orders_cv` × `sales_shipments_cv` 조인: 수주→출하 리드타임 45~77일, 평균 60일, 분할출하 0건.

- 미출하 주문 1,814건:
  - 2026-04~06 수주분 1,232건 = 미출하 잔고 후보(상태 확인 필요) (PL-01 224.9만 EA, PL-02 86.5만 EA)
  - 나머지 582건(2023-11부터 매월 20~30건) = 상태 불명 장기 미출하, 취소인지 누락인지 확인 필요
- 약속 납기는 `order_date`+60일(최대 77일)로 도출하는 가정.

### 계열 수요 누락
- `m_customer_cv`에 Masil 없음.

- `sc_purchase_orders_ms`에 공급처 Corevia인 PL-02 발주 8.8만 EA(SPO-0001 등, 2026-06-22~26, 리드타임 12주) → Corevia 영업 데이터에 안 보임.

- `sku_weekly_sales_ms` Masil 더마 판매 주 2.4만~2.8만 EA.

### C-101
- `sales_customer_summary_cv` `booking_yoy_pct`: 2026-04 −14.3 / 05 −22.0 / 06 −33.7. 같은 기간 출하 142억 → 149억 → 123억(유지).

- `sales_meeting_notes_cv`에 2nd vendor 정황. `sales_memo_cv`는 "출하 기준 정상" 보고 → 수주·출하 시점 차이.

- `fin_ar_aging_cv` C-101 미회수 335억, AR-C00001 24.6억 101일 경과.

### 원가·환율
- RFP는 `applied_unit_cost_krw`를 원가로 쓰라 하지만 이는 **원료 kg당 단가**(PL-02 2026-06 250,626원).

- `consumed_qty`×단가 / 생산량 → EA당 원료비 PL-01 4,293원, PL-02 10,635원(2026-04~06).

- 판가 PL-02 15.8달러 × 1,478.29원(`ext_fx_daily` 6/30) = 23,357원. 가공비 데이터 없음.

- kg 단가를 그대로 쓰면 "적자" 오판.

### 리스크 연결
- PL-02 보류 배치 2건(B-02-2602-01, B-02-2603-01, LOT-B-2602-P) + RFP 조건 **리콜비 공급자 부담** → 진행 중 품질 이슈와 정면 충돌.

- RFP 조건: USD 결제, 지연 페널티 월 3%.

- M-B V-205 독점·MOQ·자동갱신(`m_material_cv`). C-201 회수조건·여신 이력 없음.

- 입찰 마감 ≠ 납품 개시일.

### 승인 권한
- `approval_authority_policy.md`: 입찰 참여·투자 = CEO/이사회, C-101 재협상 = 영업 임원.

## 2. 솔루션안

### 안 A (추천): 입찰 공급약속 심사(Bid-Commit Desk)
- **사용자·결정**: 영업기획 기안, CEO/이사회가 입찰 참여와 조건 결정
- **흐름**:
  1. RFP 접수, 바이어 질의(초도·분할 납품일) 등록
  2. 월 버킷 공급 여유 시뮬레이션: 단위·일정·배정 가정을 정의한 뒤 능력·기존 약속·계열 수요·보류 재고를 중복 없이 반영
  3. 시나리오 비교: OPT-02 선행+OPT-01 단계, 단가 −5/−10%, 환율
  4. AI가 제안 조건(물량 상한, 납품 개시일, 페널티 상한)·근거 생성해 상신
  5. 승인 → 상태 변경 + 후속 작업: 생산 가배정, 조달에 M-B 증량 요청, 재무·그룹에 CAPEX 배분 요청
- **AI 역할**: RFP·회의록 조건과 모순 추출(마감≠납기, 87% 단순평균) / 미확인 항목 확인요청 작업 / 조건부 제안서 초안
- **조건 변경**: 바이어 "초도 2026-10 전량" 회신 → OPT-01 불가, 분할안 재계산 / C-101 발주 회복 → C-201 배분 축소 / 환율 하락 → 공헌이익 재평가
- **정보 부족·거절**: 납기 미확인 주문은 "가정" 표시 + 영업 확인 요청 / CEO 거절 → 축소안(더마 40%만) 재계산 또는 No-Bid 기록
- **필수 확장**: 기존 주문 약속 원장(도출 납기·확인 상태) + 바이어 질의 회신(합성)
- **다른 부서 영향**: Masil 더마 공급 보호, 조달 M-B MOQ·독점 제약, 그룹 300억·covenant
- **난이도**: 중 (계산 단순, 상태 전이가 핵심)

### 안 B: 납기약속 보호 원장 + 주문 단위 CTP
- 기존 주문·Masil 발주를 약속 원장으로 관리, 신규 수요 시 충돌 주문 탐색. 납기 변경은 고객 동의 + 영업 임원 승인. 운영성 강하나 입찰 결정 서사 약함. 난이도 하.

### 안 C: 입찰-여신 통합 Deal Desk
- 공헌이익, USD 노출, 페널티 3%/월, 리콜 전가, 회수조건 심사. 생산 여력 연결이 약해 핵심을 비껴감. 난이도 중하.

## 3. 빠지기 쉬운 함정
1. 입찰 마감 3주를 납기로 읽음
2. 공장 평균 가동률이나 87% 단순평균 사용
3. 기초 600만 EA 병목 누락
4. `capacity_qty` 단위를 검증 없이 사용 (배치 실적과 불일치)
5. kg당 원가를 EA당 원가로 사용
6. C-101 수주 감소를 "여력 확보"로 해석
7. 상태 불명 미출하 582건을 확인 없이 잔고로 확정하거나 제외
8. Masil 계열 발주 누락
9. AI가 입찰 참여 자동 확정 (권한 위반)
10. 시뮬레이터 BI만, 승인 이후 상태 변경·후속 작업 없음
11. 모든 회신을 유리하게 가정
