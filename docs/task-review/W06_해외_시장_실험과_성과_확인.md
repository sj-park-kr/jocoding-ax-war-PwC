# W06 해외 시장 실험과 성과 확인

## 최종 승인자 검토 (2026-11-11)

**최종 78/100 · 8위** — 기획 / 데이터 / 운영 구현 가능성 / 변경·예외 = **18 / 19 / 22 / 19**. 보완 반영 전에는 72점(17 / 18 / 21 / 16)이었다. 배점은 20/25/30/25이며 공식 배점이 아니다. 아래 승인 조건을 설계에 반영했다고 가정한 제안 점수이고 구현 완료 승인은 아니다. [공통 기준과 최종 순위](00_종합_업무선택.md).

정보 공백만으로 낮은 고득점 상한을 단정한 평가는 철회한다. 다만 모집단과 승인·FX 설계 오류를 수정해야 한다.

- 해외 주문 **9,001/15,650건**은 확인. 해외 확대 기안은 **15건**(일본·미국·동남아 각 5건), 기대 ROAS **9.167~11.25배**다.

- 7/1 기준 90일 관찰 완료 고객의 재구매율: 일본 **231/2,464=9.38%**, 미국 **244/2,222=10.98%**, 동남아 **197/1,797=10.96%**, 국내 **589/4,204=14.01%**. 미성숙 해외 고객은 **1,216명**이다. 기존 비율은 전체 고객을 분모로 한 값이다.

- 국가·채널은 일대일이지만 인플루언서 활동 기간은 겹친다. 모든 변수의 완전 교락이라는 표현은 과장이다. 비교군 부재로 증분효과를 확정할 수 없다는 결론은 유지한다.

- 대표 거절 후 소액 축소해도 **기안 총액 1억원·covenant 우선 규정**을 다시 적용한다. 팀 전결로 자동 우회하지 않는다.

- 실질 ROAS 손익분기는 **0**. ≥1은 자체 수익 목표다. 원화 확정 과거 거래에 USD ±5%를 직접 적용하지 않고 미래 외화 노출 비용·시점을 가정으로 정의한다.

- SPO 5.24억원은 1건이며 전체 PO 지급은 **37.4976억원**이다. SKU-1003 커버는 **4.3주**다.

- **승인 조건:** 국가·채널 1개, 운영조건 회신→비용·할당 변경→보류/중단 흐름. 다국가 확대와 성공률 비교는 후순위. 근거: A05, 캠페인·기안·주문·재구매·재고·권한 정책.

### 보완 반영 재평가 (2026-11-11)

- **회복한 감점 (+6):** 국가·채널 1개로 범위 한정(기획 +1, 구현 +1). 재구매율 모집단 정정(데이터 +1). 축소안에 총액·covenant 권한 재적용(예외 +1). 손익분기 0 정정(예외 +1). 중단 사례와 운영조건 회신의 모의 처리(예외 +1).

- **보완해도 남는 감점:** 비교군, 국가별 운영조건, 엔화 등 환율이 원본에 없다. 실험 관측값과 운영 중 AI의 입력이 전부 합성이다.

## 1. 데이터에서 확인한 사실

### 함정·공백
1. **비교군 없음**: 모든 주문에 `campaign_id`(미귀속 0건) → 유기 매출 기준선 없음, 증분(lift) 계산 불가.
2. **국가·채널 효과 분리 어려움**: 국가 1개 = 채널 1개(CH-05/06/07), 인플루언서 국가당 2명, 캠페인 반기 순차 → 비교군 부재와 국가·채널 대응으로 증분효과 식별 어려움(모든 변수의 완전 교락은 아님). BPMN의 "실험군·비교군 없음"이 데이터로 확인.
3. **기안 기대 GMV 기계적**: `expected_gmv_krw / requested_budget_krw` 약 9.167~11.25배 일정 vs 실측 1.6~2.5배 → 핵심 판단 포인트.
4. **운영조건 데이터 사실상 없음**: 해외 배송비(CH-06 2,755~3,474원)가 국내 자사몰(3,435원)과 같은 수준. 통관·관세·인증(MoCRA, 일본 약기법, ASEAN 신고)·배송 SLA 컬럼 없음. `ext_fx_daily.csv`는 USD/KRW만(2024-07~2026-06, 1,319~1,484), JPY·동남아 통화 없음. `data_dictionary.md`상 해외 금액은 "판매 시점 원화 확정값" → 환리스크 역산 불가.
5. **재고 차원 불일치**: `sku_weekly_sales_ms`·`sku_inventory_ms`엔 채널·국가 차원 없음(전사 규모), 마케팅은 대표 표본(A05) → 국가별 재고 할당은 가정 필요.
6. **유입-주문 불일치**: `mkt_traffic_inflow_ms` conversions(CH-05 7,449) ≠ 주문(3,400). CH-04는 유입만 있고 주문 0.
7. **재구매 미성숙 고객**: 7/1 기준 90일 미성숙 해외 고객 **1,216명** → 비재구매로 단정 금지(A05).
8. **벤치마크 한계**: `ext_channel_benchmark`, `ext_category_growth`에 국가 차원 없음.

### 다른 부서 연결 단초
- 더마 SKU-1001~1004는 해외에선 동남아만 판매(600건, CMP-0018). 재고 커버 2.2~4.3주, 4종 중 3종은 안전재고 4주 미달, 리드타임 12주, MOQ 2만~2.4만개(`m_sku_ms`).

- `approval_authority_policy.md`: 1천만원 초과 → Masil 대표. PLAN-004(10.18M), PLAN-005(10.03M)가 경계 사례. covenant 하회 구간에선 CEO 승인 우선.

**합성 필요도: 중상** — 성과는 원본으로 충분, 실험 관측값·운영조건 견적(물류·인증·FX)·회신은 합성/가정.

## 2. 솔루션안

### A안 (최선): 해외 파일럿 Stage-gate 운영 콘솔
- **사용자·결정**: 마케팅 해외담당 기안, 마케팅팀장 또는 Masil 대표가 "파일럿 집행·확대·중단" 결정
- **흐름**:
  1. PLAN-0xx 선택 또는 국가×채널×SKU 입력
  2. 원본 기준선 산출(실질 ROAS는 A05 §5 공헌이익 기준)
  3. AI가 기안 기대 GMV(11배) vs 실측 차이 지적, 사전가설·성공/중단 기준 초안(예: 실질 ROAS ≥ 1, 반품률 ≤ 10%, 재고 커버 ≥ 4주 유지)
  4. 운영조건 체크리스트(인증·통관·배송 SLA·FX 밴드·재고 할당) 확인 요청
  5. 금액·covenant 여부로 승인자 라우팅
  6. 승인 → `PILOT_RUNNING`, SCM 할당 요청, 재무 현금유출일 전달
  7. 주차별 관측값 입력 → AI gate 판정 초안(확대/유지/중단)
  8. 승인 → 상태 변경, 확대 시 SCM 발주 신호
- **AI 역할**: 기안 가정 감사, 가설·기준 초안, 관측값 판정, 회신 텍스트 해석·조건 갱신
- **조건 변경**: 동남아 물류 견적 3배 회신 → 실질 ROAS 재계산·Gate 강등 / USD/KRW ±5% → 미국 마진 재판정
- **정보 부족·거절**: 인증 미확인 → `HOLD_INFO` + 확인 작업 / 대표 거절 → 축소안의 총액·covenant 권한 재판정 후 재상신 또는 SKU 대체(더마→선케어)
- **필수 확장**: 국가별 운영조건 레지스트리(인증·SLA·통관비) + Stage-gate 규칙
- **다른 부서 영향**: SCM(더마 커버 4주 미만·리드타임 12주 → 파일럿 물량 상한), 재무(covenant 승인 경로)
- **난이도**: 중상 (범위를 1~2개 국가로 고정해야 6일 가능)

### B안: 해외 확대 기안 심사기
- 해외 기안 15건 일괄 감사, 기대 GMV를 실측 ROAS로 재산정, 승인 라우팅 후 조건부 승인·축소·반려 관리. 구현 하. 실험 설계 요소 약하고 W02와 겹침.

### C안: 국가 진입 운영조건 리스크 트래커
- 인증·물류·FX 시나리오 Go/No-go 도구. 데이터 대부분 합성, 성과 연결 약함.

## 3. 함정·리스크
- 국가 간 순위를 인과로 주장("일본이 최고") → 교락 때문에 감점. 비교 유효 범위 명시.

- 표본 GMV를 전사 매출·현금과 합산, 기안 기대 GMV 그대로 사용 (A05).

- 공헌이익 이중 차감: `influencer_fee_krw`는 `ad_cost_krw`에 포함. 쿠폰·환불 재차감 금지.

- 합성 관측값을 성공 쪽으로만 → A03 불인정. 중단(kill) 사례 반드시 시연.

- 운영조건을 체크박스로만 → 마진·SLA 계산과 상태를 바꾸지 않으면 BI·권고문 판정.

- FX: USD만 → JPY·동남아 통화는 명시적 가정.

- covenant 판정은 W01·재무 13주 재전망에 의존. `fin_cash_forecast_ms`에 PO 전체 지급(37.4976억, 7/21; 5.24억은 SPO-0001) 반영 여부 미검증.

- 범위 과다: 3개국 전부 하면 실패. **동남아 더마(재고 제약) + 미국 선케어(FX) 두 사례로 좁히기** 권장.
