# W02 인플루언서 계약과 캠페인 집행

## 최종 승인자 검토 (2026-11-11)

**최종 91/100 · 1위** — 기획 / 데이터 / 운영 구현 가능성 / 변경·예외 = **19 / 23 / 27 / 22**. 보완 반영 전에는 84점(18 / 22 / 25 / 19)이었다. 배점은 20/25/30/25이며 공식 배점이 아니다. 아래 승인 조건을 설계에 반영했다고 가정한 제안 점수이고 구현 완료 승인은 아니다. [공통 기준과 최종 순위](00_종합_업무선택.md).

기한이 연결된 계약·기안 처리안을 우선 추천한다. 성과 본표와 순위는 A05 기준으로 정정한다.

- 검산 가정: 주문당 원가·출고비 각 1회, 수수료는 GMV 기준, 환불 시 원가·수수료 회수 없음, 반품 행당 물류비 1회, 광고비 합계 1회. GMV에서 쿠폰을 다시 빼지 않고 환불도 1회만 차감한다.

- 실질 ROAS는 **INF-001 −0.198 / INF-005 −0.214(최하위) / INF-002 3.703(최상위)**. INF-001 공헌이익 **−61,308,789.44원**. 기존 −0.34는 쿠폰 재차감 값이다. 두 주요 대상 적자라는 결론은 유지된다.

- 기안 총액 **180,803,272원**, 7/17 5건 **70,902,290원·39.22%** 확인. 전체 캠페인 명목 ROAS는 **1.215~7.655배**. 하위 성과 5개가 요청액 상위 5개와 동일하다는 주장은 철회한다.

- 선지급으로 보이는 12건은 조건 확인 대상이며 확정 모순이 아니다. GMV 비례 배분 패턴은 확인되지만 담당자의 의도까지 입증하지 않는다.

- 계약과 기안의 상태·승인 이력을 분리한다. 발송과 수령은 별개 상태이며 미수령·기한 경과·역제안 시 재상신한다. 표본 기안의 금액을 전사 자금에 추가할 때는 규모 가정을 별도로 둔다.

- **승인 조건:** INF-001 계약 1건과 연계 기안, 통보·수령 실패, covenant 우선 라우팅, 재무 또는 SCM 제약으로 바뀌는 후속 처리까지. 계산은 코드, AI는 문서 조건 추출·회신 해석·초안에 사용한다. 근거: A05 §5, Masil 마케팅 4종·기안·캠페인·전속계약 통보서.

### 보완 반영 재평가 (2026-11-11)

- **회복한 감점 (+7):** 계약과 기안의 상태·승인 이력 분리(기획 +1). 비용 가정별 시나리오로 순위·부호 유지 여부 표시(데이터 +1). 재무 제약에 따른 승인 경로 분기와 운영 중 AI의 입력·출력 정의(구현 +2). 실행 후 정정, 기한 경과에 의한 묵시적 승인 방지, 수령 실패·역제안 재상신(예외 +3).

- **새로 확인한 사실:** 원본 스케줄 재계산의 30억원 하회 구간은 **7/21~8/22(33일)**이다. 집행일이 이 구간에 드는 기안은 **12건·99,550,557원(총액의 55.06%)**이다. 7/17 기한 5건 중 **PLAN-001·002·003은 그룹 CEO**, **PLAN-004·005는 Masil 대표 승인+그룹 보고** 대상이다. 전속계약은 별도로 CEO/이사회 사안이다. 정산일이 확정기한보다 빠른 12건과는 다른 집합이다.

- **변경 사례로 쓸 지점:** LC-0001 결제조건이 정정되면 하회 구간이 움직이므로 기안별 승인 경로를 다시 판정한다.

- **보완해도 남는 감점:** 계약 원문·성과 피 정산조건과 통보 수령 증빙이 원본에 없다. 표본 성과는 금액으로 환산할 수 없다.

## 1. 데이터에서 확인한 사실 (표본 계열은 비중·순위로만 읽음)

### 공백·이상
- 계약 원문, 성과 피 정산조건, 통보 수령 증빙, 상신·승인 이력 없음 (W02.html "미해결 지점").

## 2. 솔루션안

### A안 (최선): 기한 연동 결정 큐 — 갱신과 기안을 한 케이스로
- **사용자·결정**: 마케팅 기안 / 재무 검증 / Masil 대표가 기안, CEO·이사회가 전속계약 결정
- **흐름**: 기안·통보서 접수 → 인플루언서 기준 연결 → 실질 공헌이익, 집행 비중 vs 실질 순위 → D-day 순 정렬 → 건별 대안(승인/감액/재배분/부결; 계약은 갱신/조건변경 통보/해지 통보) → 권한 라우팅 → 승인 → 상태 변경(통보 발송됨·계약 상태) → SCM에 판매계획 변경, 재무에 현금유출 일정 전달
- **AI 역할**: 기안·통보서 조건 추출 / "기안 부결인데 계약 미결" 같은 불일치 탐지 / 표본·풀스케일 숫자 혼용 차단 근거 생성 / 조건변경 통보안 작성(고정 피 인하 + 성과 피 전환)
- **조건 변경**: 에이전시 역제안(고정 피 20억) / 반품 정정 데이터 유입 / 재전망으로 covenant 하회 발생 → 승인권 CEO로 상향
- **예외**: 계약 원문·수령 증빙 없음 → "통보 불가·확인요청" / 대표가 기안 반려해도 계약 케이스는 열린 채 07-15 경보 / 기한 경과 → 자동 확정·위약금 시나리오
- **필수 확장**: 계약 협상 시뮬레이터(고정→성과 피 구조)
- **다른 부서 영향**: SCM(캠페인 SKU 재고 커버·품절), 재무(covenant 구간 승인 상향)
- **난이도**: 중 (데이터 작음, 정적 계산 + DB 상태 테이블 1개)

### B안: 실질성과 정산 엔진 + 확대 기안 자동 심사
- 기안 25건 건별 전결/상신 판정 + 재배분안. 쉽지만 계약 갱신이 빠지면 핵심 질문 놓침, BI처럼 보일 위험 큼.

### C안: 전속계약 라이프사이클 관리
- 통보 기한 원장 + 갱신 심의 패키지. 시연 임팩트 강하나 계약 1건뿐이라 근거 얇고 합성 계약 필요.

## 3. 함정·리스크
1. 표본 × 풀스케일 곱하기("28억 × 적자율 = X억 손실") → 즉시 감점. 나란히만 놓을 것.
2. 쿠폰·인플루언서 피 이중차감, 정의 충돌 미명시.
3. 기안만 처리하고 계약 방치 → 출제 의도의 핵심 오답.
4. "부결했으니 끝" → BPMN '아니오' 종료는 재검토 상태일 뿐 미갱신 확정 아님.
5. 마케팅 감축을 자금 해법으로 제시 → 회의록이 명시 금지.
6. 답이 회의록에 거의 다 적혀 있음 → 차별화는 상태 머신·권한 라우팅·협상 대안 작동에서.
7. 실질 공헌이익 비용 가정(주문당 원가 1회, 환불 시 원가 회수 여부) 미명시.

## 4. 출제자 관점
- 출제자가 회의록에 함정을 가장 두껍게 심은 업무. 성과 역전·기한·권한·covenant 하회가 한 업무에서 맞물림.

- 평범한 답안: 명목 ROAS 순위표 + "INF-001 재검토 권고" 메모. 통보 기한 상태 관리·권한 라우팅 없음.

- 실질 상위는 INF-002, INF-009.

- 약점: 몰림·평범한 BI 답안과 겹칠 위험.
