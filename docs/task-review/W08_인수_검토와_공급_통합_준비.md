# W08 인수 검토와 공급 통합 준비

## 최종 승인자 검토 (2026-11-11)

**최종 80/100 · 6위** — 기획 / 데이터 / 운영 구현 가능성 / 변경·예외 = **18 / 21 / 22 / 19**. 보완 반영 전에는 73점·7위(17 / 20 / 20 / 16)였다. 배점은 20/25/30/25이며 공식 배점이 아니다. 아래 승인 조건을 설계에 반영했다고 가정한 제안 점수이고 구현 완료 승인은 아니다. [공통 기준과 최종 순위](00_종합_업무선택.md).

증거에 따른 투자 선행조건 관리안은 타당하다. 거래조건 오류와 전망·가치 단정을 수정하고 공급 트랙은 축소한다.

- 제안서는 **순부채 없음·EV=지분가치**, 50% 150억원, 잔여 50%는 **첫 클로징 후 12개월 내 동일 기준 150억원 콜옵션**을 명시한다. 행사가 미정이라는 문구는 오류다. 실제 계약 체결·지배력 조건은 별도 확인 대상이다.

- 10개 분기 비용합계·EBITDA 재계산 확인. 반복 3항목은 가산하지 않고 2024Q3 설비이전 3억원만 인정하면 2024 정상화 **16.277억원**, 2025 **18.745억원**이다.

- LTM EBITDA **22.2663억원** ×11.5=**256.06245억원**. 300억원은 **17.16% 프리미엄**이며 적정가의 확정 판단이 아니다. 2026E **26.4억원** ×11.5=303.6억원은 전망 시나리오이고 300억원과 차이는 **1.19%**다.

- CL-01 이탈 후 **−6.204억원**은 고객 마진을 전사 39%로 놓고 나머지 매출·비용을 유지한 가정이다. 고객별 마진·비용절감 근거가 없다.

- 공급 다변화 가설은 있지만 대체재 적격성·시너지 금액은 미검증이다. V-205 effective_date만으로 계약 실제 갱신일·만기를 확정하지 않는다.

- **승인 조건:** CP 수령→검토→조건 충족/보류→재상신. 미도착은 미충족·미확인으로 두고 부정적 증거와 구분한다. CP 면제·약정 해제·콜옵션 조건은 별도 권한과 계약상 근거가 필요하다. 집행 완료 자금을 자동 해제하지 않는다.

### 보완 반영 재평가 (2026-11-11)

- **회복한 감점 (+7):** 투자 판단과 원료 사용 승인 분리(기획 +1). 거래조건 정정(데이터 +1). 선행조건 1건의 상태 흐름으로 범위 축소(구현 +2). 미도착과 부정적 증거 구분(예외 +1). 집행 자금 자동 해제 금지(예외 +1). 선행조건 면제 권한과 재상신의 모의 처리(예외 +1).

- **보완해도 남는 감점:** 계약 원문, Celtonic 원료 규격, 고객별 마진이 원본에 없다. 범위 축소 효과가 커서 W05보다 한 단계 올라갔다.

## 1. 데이터에서 확인한 사실

### 재무 논리 (QoE)
- `celtonic_quarterly_pl.csv` 분기 실제 금액: `sga_cert_reg_krw`(인증등록비)·`sga_claim_settle_krw`(클레임정산)·`sga_retention_bonus_krw`(리텐션보너스)는 **10개 분기 모두 발생**. `sga_equip_relocation_krw`(설비이전)만 2024Q3 3억 1회.

- 그런데 경영진은 앞의 세 항목을 "예외적"이라 설명(`celtonic_management_interview.md`).

- 세 항목 추이: 2024년 7억(매출 5.8%) → 2025년 15억(9.2%) → 2026E 22억(10%).

- 매도측: 조정 EBITDA 48.4억(`celtonic_financials_raw.csv` 2026E `adjusted_ebitda_reported_krw`) × 배수 11.5배(`strat_valuation_multiples.csv` 활성원료) = 557억 → 300억은 "46% 할인" 주장.
  - **전망 기반 정상화 EBITDA 2026E 26.4억 × 11.5 = 303.6억 → 300억은 1.19% 낮음.**
  - LTM(2025Q3~2026Q2) EBITDA 22.27억 기준 256억 → 300억은 **11.5배 적용 LTM 비교가치 대비 17.16% 프리미엄**.

- 2026E는 연간 전망. 7/1 기준 실적은 상반기뿐: 매출 101.2억(전망 220억의 46%), EBITDA 12.1억.

## 2. 솔루션안

### A안: 선행조건(CP) 게이트형 투자 승인 시스템 (재무 트랙)
- **사용자·결정**: 전략기획 기안, 재무 의견, CEO/이사회 결정(`approval_authority_policy.md`)
- **흐름**:
  1. 실사 자료 수신
  2. 코드로 조정 항목 발생 분기 수를 계산하고 AI가 문서 설명과 반복성 근거를 검토
  3. 정상화 EBITDA·가치 범위(LTM / 2026E / CL-01 이탈 시나리오) 계산
  4. CP 목록 생성. 상태: 미확인 → 요청 → 증빙 수령 → 충족/불충족/면제
  5. 이사회에 조건부 승인안 상신
  6. 승인 → 그룹 자금 원장 150억 '미배정' → '조건부 약정(CP 미충족 시 해제)'
  7. 실사 질의서 발행
- **AI 역할**: 반복성 판정, 실사 답변(계약 원문 등)에서 단가·해지·갱신 조건 추출, CP 상태 갱신 제안, 가치 재계산
- **조건 변경**: CL-01 갱신 실패 회신 → EBITDA·가치 재계산 → 가격 재협상안 또는 콜옵션 미행사안 재상신
- **정보 부족·거절**: 계약 원문 기한 미도착 → 해당 CP '미확인·기한경과', 자동 보류 / 이사회 거절 → 150억 약정 해제, 재배분 대상
- **난이도**: 중하

- CP를 **인수 전(Pre-closing)**: CL-01 갱신, 계약 원문 확보, 정상화 EBITDA 확정 / **인수 후 검증(Post-closing)**: M-B 대체 시험, V-205 위약금 산정으로 분리.
