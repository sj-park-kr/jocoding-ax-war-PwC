- zip 포함: 키 이름만 적은 `.env.example`, 직접 만든 AI 지침·스킬 파일(`CLAUDE.md`, `AGENTS.md`, `.claude/skills` 등) → AI 활용 과정 채점에 사용

## 3. 시연 영상
**파일 규격**: MP4/MOV/WebM, 최대 1GB, 5분 이내 권장(초과분도 심사), 1080p 권장, 원본 그대로 업로드

**필수 촬영 기준**
- 음성 해설 필수 (본인 목소리 아니어도 됨)
- 장면마다 실제 작동인지 모의 처리인지 말로 설명
- 빨리 감은 구간은 화면에 배속 표시

**자유 항목**: 얼굴 노출 불필요, 편집 방식 제한 없음. 설계 이유·데이터 근거는 영상이 아닌 설계 설명에 작성

**장면 구성 순서**
1. 소개(30초): 고른 업무, 누구의 어떤 결정을 돕는지
2. 정상 흐름: 입력 → 데이터 확인 → 계산·판단 → 근거·대안 → 승인·후속 처리 → 상태 기록
3. 조건 변경: 입력을 바꿔 판단·계획 재검증. 결론 유지 시 그 근거 제시
4. 정보 부족 또는 승인 거절: 확인 요청·보류·재상신·대안 등 다음 행동 (3번과 합쳐도 됨)
5. 필수 확장과 다른 부서 영향: 앞 장면 중 어디에서 쓰였는지
6. 추가 확장 (선택): 해 본 것이 있을 때만

## 4. AI 활용 기록
기록 없으면 AI 활용 과정 미채점. 두 방식 모두 감점 없음.

**제출 방법**
- **실시간 기록 (자동 수집)**: Claude Code, Codex, Antigravity 대상. 풀이 환경에서 기록 연결 후 작업하면 자동 반영. 수집 현황은 제출 가이드 페이지에서 확인(로그인 필요)
- **기록 파일 업로드**: 기타 도구 사용 또는 실시간 기록 누락분 보완. 로컬 세션 로그 첨부. 형식 txt/log/md/json/jsonl/zip, 최대 200MB. 실시간 기록과 같은 기준으로 필터링 저장

**수집 항목**: 프롬프트 / AI 최종 답변 / AI 작업 내역(도구·스킬 이름, 프로젝트 폴더 내 실행 명령, 작업 파일 이름, 실행 결과 크기·종료 코드) / 작업 환경(모델, 승인 모드, OS) / 시각·순서(수신 시각, 요청별 소요 시간, 세션·요청 번호)

**미수집 항목**: 도구 실행 결과(파일 내용, 명령 출력, 검색 결과), AI가 파일에 쓴 내용, 프로젝트 폴더 밖 작업, MCP·웹 검색·하위 에이전트 입력, 사용자 이름 포함 경로

**쓰임·보관**: 조코딩AX파트너스 채점에만 사용(출제 기업에는 분석 결과만 전달). 수신/업로드일로부터 365일 후 자동 삭제
